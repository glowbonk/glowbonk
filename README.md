<h3 align="center">Turning ideas into small, useful software.</h3>

I'm a backend engineer who spends most days wiring together Go services and Python APIs, usually with PostgreSQL and Redis underneath. I care about clean API contracts, databases that don't lie to you, and distributed systems that fail predictably instead of silently. Most of what I build runs in Docker and talks to other services over HTTP or gRPC.

#### What I do

- 🔭 Breaking a monolith into Go microservices with gRPC and Redis streams.
- usually building small tools nobody asked for
- keeps notes about clean API design that will never be published
